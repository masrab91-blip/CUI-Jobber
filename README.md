# CUI-Jobber

Winter snow-entry ops for Propel ↔ CUI, run on Marc's **propel-mac** worker.

See **[WINTER_OPS.md](./WINTER_OPS.md)** for the live runbook, property list, and LaunchAgent setup.

Quick start on the Mac:

```bash
git clone https://github.com/masrab91-blip/CUI-Jobber.git ~/CUI-Jobber
cd ~/CUI-Jobber
# put API key in ~/.config/propel/cursor-api-key (never commit it)
./scripts/mac/start-winter-entry.sh
```
